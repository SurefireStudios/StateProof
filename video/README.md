# Walkthrough video

A deterministic pipeline: Playwright drives the live product and records it,
FFmpeg composes. No frame is generated by a model, no narration is synthesised,
and every number on screen comes from the running application.

## Commands

```bash
pnpm video:capture     # record 12 clips from the deployment
pnpm video:render      # cards, callouts, concat, captions
pnpm video:script      # voiceover + teleprompter, timed from the render
pnpm video:verify      # ffprobe checks, writes the report
pnpm video:mux -- --audio video/input/voiceover.wav
```

Capture against a local build instead of the deployment:

```bash
pnpm video:capture -- --base http://localhost:4180
```

Re-shoot one clip without redoing the take:

```bash
pnpm video:capture -- --only comparison
```

## Output

| File | What it is |
| --- | --- |
| `output/stateproof-walkthrough-silent.mp4` | The cut, no audio — narrate over this |
| `output/stateproof-walkthrough-captioned.mp4` | Same cut with captions burnt in |
| `output/stateproof-final-narrated.mp4` | Produced by `video:mux` once the WAV exists |
| `output/cue-sheet.json` | Measured duration of every segment |
| `output/video-verification-report.md` | ffprobe results |
| `captions.srt` | Generated from measured timings, not written by hand |

`output/` and `input/*.wav` are git-ignored — they are large and regenerable.
The scripts, shot list, captions and reports are tracked.

## How it holds together

`src/clips.ts` is the shot list as data and `src/narration.ts` is the script.
Everything else reads those two: the capture paces itself to the clip durations,
the render lays them out, the SRT is timed from the durations the render
actually produced, and the teleprompter and voiceover script are written from
the same lines. A caption cannot claim a second the picture does not have.

## Deliberate choices

- **Viewport recording, not screen recording.** No browser chrome, no address
  bar, no profile, no bookmarks — nothing to redact.
- **One context per clip.** A failed clip is re-shot alone rather than spoiling
  a twelve-minute take.
- **A drawn cursor.** Playwright's mouse leaves no trace on video, and a click
  with no pointer on screen reads as a glitch.
- **The voice is never time-stretched.** If the read does not fit, the mux says
  so and stops.

## Known limits

- Capture depends on the deployment being awake. On a cold instance the first
  clip can catch a loading frame; re-shoot it with `--only`.
- Clip pacing is wall-clock, not frame-locked. Durations vary by a few tenths
  between runs; the render trims each clip to its planned length, so the cut is
  stable even when the capture is not.
