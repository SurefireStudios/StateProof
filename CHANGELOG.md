# Changelog

All notable changes to StateProof are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/) from `v1.0.0` onwards.

The evaluation itself has its own record: every iteration, including the two
that failed, is in [IMPROVEMENT_CHANGELOG.md](IMPROVEMENT_CHANGELOG.md) with the
run artifacts that justify it. Nothing below changes a measured result.

## [Unreleased]

## [1.0.0] - 2026-09-08

First public release. The verification engine, the benchmark, the frozen
evaluation and the product are unchanged from the final competition submission;
this release makes the repository a maintained open-source project.

### Added

- A flagship `README.md`: value proposition, features, a worked verification
  example, architecture diagram, screenshots, use cases and roadmap.
- `CONTRIBUTING.md`, `SECURITY.md` (private vulnerability reporting), and this
  `CHANGELOG.md`.
- GitHub issue templates (bug report, feature request, benchmark case
  proposal) and a pull request template.
- GitHub Actions: `CI` runs typecheck, the test suite, both fixture
  validators, the credential-free reproduction, the artifact-integrity check,
  both builds, the product tests and the secret scan on Ubuntu and Windows, and
  builds and boots the Docker image. `CodeQL` scans on push, pull request and
  weekly. `Release` verifies a tag offline and attaches source, evidence
  dashboard and sample-run archives.
- Dependabot for npm, GitHub Actions and Docker base images.
- `docs/roadmap.md`, mirrored by issues labelled `roadmap`.
- `docs/media/`: screenshots, an architecture diagram and a walkthrough GIF,
  regenerated from the running product by `pnpm media:capture`.

### Changed

- `package.json` carries a description, keywords, homepage and issue tracker,
  and moves to `1.0.0`.

## [stateproof-submission-final] - 2026-08-29

The final competition submission.

### Added

- `apps/product`: the interactive application around the frozen engine. A
  landing page whose worked example is generated by the verifier on request, a
  credential-free demo of `PBH-B03`, a run inspector with clickable evidence
  references, an import screen that validates and then verifies a run package,
  a benchmark view, and JSON/Markdown evidence export.
- A single-container deployment (`Dockerfile`, `railway.json`) serving the
  product and the evidence dashboard on one origin with no credential.
- `samples/stateproof-sample-run.zip`, a gold-isolated sample run package.
- API cost estimates against a dated, sourced price list
  (`submission/final-pricing-manifest.json`).
- Human-review disclosure on every surface that shows a verdict.

### Fixed

- The product client set `style` attributes that its own Content-Security-Policy
  silently dropped; every rule now lives in the stylesheet and a test enforces it.
- A whole-trajectory schema violation in an imported package escaped as an HTTP
  500; it is now a field-level validation error naming the offending line.

### Removed

- Working material that was not part of the deliverable: the video capture rig,
  planning notes, a hosting guide superseded by `docs/live-deployment.md`.

## [stateproof-submission-v1] - 2026-08-28

### Added

- The one-time locked evaluation: four held-out cases run exactly once after the
  source freeze, under a protocol that refuses a second attempt and records
  every attempt in an append-only ledger.
- `pnpm reproduce`: credential-free replay of all twelve Hard cases from the
  committed contract bundle, 27 checks.
- `pnpm test:clean-reproduction`: a fresh clone in a temporary directory with
  no `.env`, no `node_modules` and both credential variables removed.
- `submission/`: the final evaluation, claims-to-evidence map, run registry,
  package manifest and reproduction manifest, all generated from pinned
  artifacts.

## [stateproof-evaluation-freeze-v1] - 2026-08-28

The source freeze before the locked evaluation. Prompts, benchmark, evaluator,
verifier and lockfile were frozen at this commit and have not changed since.

### Added

- `PhantomBench-12` (Core) and `PhantomBench-Hard-12`, each with an 8/4
  development/locked split, deterministic schema and semantic validation, and a
  gold-isolation package boundary.
- The frozen frontier baseline evaluator (`prompts/baseline-evaluator/v2.md`).
- Contract Agent v1, v2 and v3, with the assertion DSL (`2.1.0`), semantic
  contract lint, task-fingerprint caching and fail-closed warm verification.
- The deterministic verifier, requirement-level metrics, and the static
  evidence dashboard generated from pinned artifacts.
